# LearnHub - Course Selling Website Landing Page

A responsive landing page for an online course platform built with HTML, CSS, vanilla JavaScript, and Bootstrap 5.

## Features

- Modern and responsive design works on all devices
- Interactive navigation with smooth scrolling
- Course cards with hover effects
- Pricing section with featured plan
- Testimonials from students
- Contact form with form validation
- Animated elements on scroll

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Bootstrap 5
- Font Awesome Icons
- Google Fonts
- Animate.css

## Setup Instructions

1. Clone or download this repository
2. Open `index.html` in your browser

That's it! No build tools or dependencies needed to run the project.

## File Structure

- `index.html` - Main HTML document
- `styles.css` - Custom CSS styles
- `script.js` - JavaScript for interactivity
- `README.md` - Project documentation

## Customization

You can easily customize this landing page by:

1. Changing the color scheme in the CSS `:root` variables
2. Replacing placeholder images with your own
3. Updating text content and course information
4. Adding or removing sections as needed

## Browser Support

This website works on all modern browsers including:

- Chrome
- Firefox
- Safari
- Edge
- Opera
